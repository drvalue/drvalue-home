## 남은 것

우선순위 순이다.

1. **특허 증서 2장의 운영본을 바꾼다.** 새 사이트는 개인정보 칸을 덮은 사본을
   걸었다(2026-09-18). 운영 서버의 원본은 아직 그대로 열려 있다.
2. **게시판 API 해시 노출을 게이트웨이 쪽에 알린다.**
3. **관리 도구(Directus)를 새 서버에 올린다.** 올릴 곳이 정해져야 그다음이
   전부 움직인다.
4. **전환 날짜를 정한다.** 정해지면 당일에 게시판 글을 다시 옮긴다.
5. ~~디자인 통일~~ — 2026-09-18 끝. 공개 장 전부 새 틀(SolutionShell + data-rv).
   옛 꾸밈은 숨김 장 patent_old 하나만 남았다.
6. 화면 채우기 — 연혁 설명 8건, 한건 그림 1장, 규제검증 교체 그림 1장.
   전부 자료가 와야 한다.
7. 게시판 글 5건(공지 3·보도 2)은 로컬 관리 도구에 있다. 2026-09-18 문체를
   사람 말로 다시 썼다(이모지·체크리스트·「앞으로도 ~해 나가겠습니다」 제거,
   사실·URL 그대로). 운영 관리 도구가 서면(3번) 거기에도 넣어야 한다. 윤문본과 넣는 스크립트는
   저장소 밖 `~/drvalue-private/board_posts_윤문본.md`·`apply_posts.py` 에 있다(저장소는 공개 배포라 안 넣는다).

## 막힌 것

- **관리자 IAM 로그인이 끝까지 안 간다.** 게이트웨이의 `root/iam` 이
  서명 위에 `x-user-*` 헤더까지 요구하는데, 그 헤더는 게이트웨이가 넣어 준다.
  지금 닿는 호스트로는 PHP 원본도 같은 이유로 403 이다.
- **`tenant_code` 값이 맞는지 못 쟀다.** 앱 토큰 없이는 판정 불가다.
- **로컬 PHP 도커가 안 뜬다.** 디스크가 차 있다. 원본 대조가 필요하면
  운영본을 원본 삼아 돌린다.
