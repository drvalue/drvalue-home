# 0018 — M.AX 장에서 겹 카드·그라데이션 판·자동 넘김을 뺀다

2026-09-28 · 사용자

## 무엇을

- 제조 흐름(FlowBand)은 사용자가 처음 준 시안(max-page-draft.html) 모양: 흰 바탕 · KPI 띠 · 여섯 칸.
- 머리말 화면은 틀 › 그라데이션 판 › 브라우저 창의 겹을 벗겨 창 하나(1px 테두리 · 옅은 그림자). 제품군 카드도 틴트 판을 뺀다.
  허브 머리말은 그 뒤 화면을 아예 뺐다 — PCB 장 대시보드와 겹치고, 넷을 섞으면 짜깁기 같다. 허브의 총괄 그림은 흐름도.
- 인증 띠는 남색 그라데이션 · 빛 번짐 · 유리 아이콘 카드 → 옅은 회색 한 줄, 세로선으로 나눈 네 칸. 허브에서는 문의 띠 바로 앞.
- 버튼은 알약 → 모서리 10px, CTA 둘레 번지는 고리 제거. 탭(제품군 · 머리말 화면)은 알약 → 밑줄 탭.
- 하위 장 기능 판(FeatureShow)은 그라데이션 판 · 상자 요점 · 알약 · 칩 · 검은 콜아웃을 걷어 흰 바탕 + 구분선. 3열의 아이콘 상자도 뺐다.
- 구역 머리 알약 라벨(`mx_kicker` · `mx_bento_k`)은 바탕 없는 브랜드색 글자. v4 장 전체가 같이 바뀐다.
- 시간이 지나야 다음 것을 보는 UI(머리말 4.2초 넘김 · 게이지 탭 6초 · 화면에 들어오면 도는 데모)는 누를 때만 움직인다.

## 왜

사용자: 「그라데이션 넣으니 보기 싫다, AI 느낌」 · 「카드에 카드에 카드」 · 「시간 지나야 다음 걸 볼 수 있는 UI 정리」.
9-22 의 어두운 판 방향(channel.io/kr/documents · meet/call 참고)을 이것이 대신한다.

## 근거

- 레퍼런스 안쪽 장 19곳(채널톡 · flex · 업스테이지 · c3.ai · Tulip, ego-browser 실측): 알약 라벨 0, 큰 흐림 효과 거의 0,
  그라데이션은 채널톡 말고는 거의 없음, 화면은 틀 없이 옅은 그림자나 단색 판 한 겹.
- 블라인드 비평(새 컨텍스트 2명씩, 라벨 없이 4장): R1(바 채널톡·flex·업스테이지) 둘 다 우리 장을 「AI 같은 것」으로 지목 →
  R2(바 Tulip·c3.ai·업스테이지 제조) 둘 다 업스테이지를 지목, 우리 장은 안 뽑힘 = 통과.
  R2 에서도 「상위 회사가 아닌 것」은 우리 장 — 이유는 흐름도의 촘촘한 AI 꼬리표, 가려진 대시보드 값, 가운데 정렬 머리말(구성 문제라 이번에 안 건드림).
- R3(같은 바, 머리말·인증 띠·기능 판을 바꾼 뒤 화면): 비평가 1 은 업스테이지, 2 는 우리 장 → 불통과. 3 라운드에서 멈췄다.
  지적은 구조(가운데 정렬 머리말 · 흐름도 AI 꼬리표 · 넘기는 제품 판)였고, 사용자가 둘을 골랐다(09-28):
  머리말·구역 제목 왼쪽 한 축(v4 장 전체, 문의 띠만 가운데) · 제품군을 고정 판 셋으로. 흐름도 꼬리표와 고객 로고는 미뤘다.
- 그 뒤 사용자: 「다른 데보다 빈약하다」 — 장식을 걷고 채울 내용(화면 · 숫자 · 대비 구역 · 움직임)을 안 넣었다. 새 캡처가 필요하다.
- 허브 머리말 그림(09-28 저녁): 사용자가 GPT 로 뽑은 추상 그림 세 안(흐름 노드 · 공장 평면도 · 문서→표)을 블라인드 비평에 돌렸고
  여섯 명 전원이 세 안 모두 「AI 같다」로 불통과. 사용자가 그래도 C안(문서→표)을 골라 일단 넣었다. 실제 전체 현황 화면을 새로 찍으면 그것으로 바꾼다.
