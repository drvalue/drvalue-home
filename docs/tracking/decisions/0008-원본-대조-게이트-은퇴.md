# 0008 · 원본 대조 검사를 통과 기준에서 뺀다

## 왜 정해야 했나

옮긴 화면이 PHP 원본과 같은지 글자 단위로 대조하는 검사가 있었다. 이관
초기에는 이것이 「무엇을 잃었나」를 잡는 유일한 장치였다. 그런데 화면을
새로 그리기 시작하면서 17장 중 14장이 실패로 나왔고, **그 14건이 전부
일부러 바꾼 것**이 됐다. 실패가 기본값이 되면 진짜 사고가 묻힌다.

## 무엇을 골랐나

**대조 결과를 통과 기준으로 삼지 않는다.** 스크립트는 지우지 않고 참고용으로
남긴다. **지울 수도 없다** — `check-home.py` 와 `check-a11y.py` 가 `compare.py` 에서
`grab()` 과 `_OPENER` 를 가져다 쓴다. 정리한다고 지우면 살아 있는 검사 둘이 같이 죽는다.

## 안 고른 것

- **고의 목록을 파일로 두고 「손댐」으로 따로 센다** — 화면을 계속 새로
  그릴 계획이라 목록이 곧 전부가 된다. 유지비만 남는다.
- **지금처럼 실패로 둔다** — 새 사고가 나도 14가 15가 되는 것뿐이라 눈에
  안 띈다.
- **새 화면만 대상에서 뺀다** — 어디까지가 「새 화면」인지 계속 판단해야 한다.

## 그래서 생긴 제약

- **「원본에서 뭘 잃었나」를 자동으로 잡아 주는 장치가 없어진다.** 그 자리를
  메우는 것은 화면별 전용 검사다 — 지금 있는 것은 홈·탭 막대·문의 모달
  셋뿐이고, 새로 만든 8장에는 없다.
- 전환 전에 한 번은 사람이 눈으로 원본과 맞춰 봐야 한다.
