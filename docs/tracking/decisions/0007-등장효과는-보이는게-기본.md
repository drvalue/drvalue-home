# 0007 · 스크롤 등장은 「보이는 것이 기본」으로 만든다

## 왜 정해야 했나

화면을 내리면 구역이 떠오르는 효과를 넣기로 했다. 흔한 방식은 CSS 에서
`opacity: 0` 으로 두고 스크립트가 켜 주는 것이다. 그런데 이 저장소에 이미
그 방식의 죽은 코드가 있었다 — `.reveal` 이 `opacity: 0` 인데 켜 주는 코드가
**한 곳도 없었다.** 누가 그 클래스를 붙이는 순간 그 글은 영원히 안 보인다.

## 무엇을 골랐나

**숨기는 일도 스크립트가 한다.** 접힌 선 아래 것만 숨기고, 관찰이 안 돌면
몇 초 뒤 전부 켠다. 브라우저에 이미 있는 `IntersectionObserver` 를 쓴다.

## 안 고른 것

- **CSS 로 숨기고 스크립트가 켠다** — 스크립트가 죽으면 글이 사라진다.
- **애니메이션 라이브러리를 들인다** — 이 하나를 위해 여러 파일을 내려받게
  된다. 참고한 사이트는 이 일에 네 개를 쓴다.
- **글자를 조각내 하나씩 띄운다** — 제목 한 줄이 DOM 조각 수십 개가 되고
  화면 읽개가 글자 단위로 읽는다.

## 그래서 생긴 제약

- 첫 화면에 보이는 것은 **건드리지 않는다.** 숨겼다 켜면 그 자체가 깜빡임이다.
- 같은 이유로 헤더의 투명/불투명 조건도 CSS 안에 둔다 — 서버가 그린 화면이
  곧 최종 상태여야 번쩍이지 않는다.
- 움직임을 줄여 달라고 한 사람에게는 아무것도 숨기지 않는다.
