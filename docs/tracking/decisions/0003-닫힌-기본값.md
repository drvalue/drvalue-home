# 0003 · 빠뜨리면 닫히는 쪽으로 기운다

## 왜 정해야 했나

환경변수가 늘었다. 배포에서 하나를 빠뜨렸을 때 무엇이 일어날지를 정해야
했다 — 그냥 도는가, 안 도는가.

## 무엇을 골랐나

**빠뜨리면 닫히거나 아예 안 뜬다.** `SESSION_SECRET` 과
`IAM_GATEWAY_SECRET`(검증이 켜져 있을 때)이 없으면 서버가 안 뜬다.
`IAM_ENFORCE_GATEWAY` 와 `SESSION_SECURE` 는 값이 없으면 **켠 것으로** 본다.

## 안 고른 것

- **그럴듯한 기본값을 준다** — 세션 서명 키에 기본값을 두면 그 값으로
  서명된 관리자 세션을 누구나 만든다.
- **경고만 찍고 돈다** — 경고는 아무도 안 본다. 열린 채로 몇 달 갈 수 있다.

## 그래서 생긴 제약

- 로컬에서 게이트웨이 없이 띄우려면 각자 `.env` 에 `false` 를 명시해야 한다.
- `SESSION_SECURE` 기본이 켜짐이라, 프록시가 TLS 를 끊는 배치에서는
  `TRUST_PROXY` 가 **새로 필수**가 됐다. 안 채우면 세션 쿠키가 오류도
  로그도 없이 안 나간다. PHP 때는 없던 설정이다.
